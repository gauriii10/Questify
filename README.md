# Questify

> **Turn your everyday tasks and learning goals into an interactive, gamified questing experience.**

Questify is a modern, full-stack web application designed to boost productivity and motivation by transforming daily habits, tasks, and learning tracks into engaging quests with rewards, progress tracking, and interactive UI elements.

---

##  Features

*  **Quest Management:** Create, track, and complete daily tasks, micro-goals, and long-term quests.
*  **XP & Level Progression:** Earn Experience Points (XP) upon completing quests to level up your profile.
*  **Interactive Dashboard:** Real-time visual progress tracking with dynamic streak counters and analytics.
*  **Gamified Themes & Badges:** Unlock achievements, badges, and personalized UI themes as you advance.
*  **Responsive Design:** Optimized for seamless performance across desktop, tablet, and mobile browsers.

---

##  Tech Stack

### **Frontend**
* **Framework / Core:** React.js / Next.js (ES6+ JavaScript / TypeScript)
* **Styling:** Tailwind CSS / CSS Modules
* **State Management:** React Context API / Redux Toolkit

### **Backend & Database**
* **Server:** Node.js & Express.js
* **Database:** MongoDB (Mongoose) / PostgreSQL
* **Authentication:** JWT (JSON Web Tokens) / OAuth
